Python API

On Ubuntu 16.04 and Ubuntu 18.04, a Dinara build includes a shared library dinara-build/dinara-install/dinara.so which behaves as a Python module. Python code can import dinara to use the functionality provided by the module. To create documentation for the Python API, see directions in dinara/docs/PythonApi/README. For the Python interpreter to find the module you must either:

  • Make sure the Python script that contains import dinara is in the same directory that contains dinara.so (dinara-build/dinara-install/bin). All Python scripts provided with Dinara are copied to that location during the build process.
  • Or, set environment variable PYTHONPATH to the name of the directory where dinara.so is located.
